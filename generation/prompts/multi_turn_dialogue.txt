You are generating a multi-turn dialogue session for a personal-memory dataset (SSPE-2 v6, Slice B).

Output format: JSON object with fields:
{
  "axis_combination": ["TEMPORAL", "ENTITY"],   // 2-3 axes from {TEMPORAL, SPATIAL, ENTITY, EVENT}
  "session_date": "YYYY-MM-DD",
  "speakers": ["name1", "name2", ...],           // 2-3 distinct first names
  "turns": [
    {"role": "name1", "content": "..."},
    {"role": "name2", "content": "..."},
    ...
  ]
}

Constraints:
- 5-12 turns total
- First turn must include explicit timestamp `[YYYY-MM-DD HH:MM]`
- Total length: 200-600 words across all turns combined
- Each axis in axis_combination must have explicit anchors visible in the dialogue:

  - SPATIAL: places, locations (city, restaurant, room, etc.)
  - ENTITY: people names (3rd parties), specific objects, brand names
  - EVENT: named actions, occasions (meeting, birthday, conference, surgery)
- Style: realistic, like a chat or text-message conversation between friends/family/colleagues
- Topic: any everyday personal-memory-relevant subject (planning, recap, casual chat)
